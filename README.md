## 适用硬件与接线

本版支持MPU6050寄存器接口的I2C模块（如GY-521），不支持串口输出姿态的其他AHRS模块。使用主板U7/IMU接口，SCL=PB10、SDA=PB11；与OLED的PB6/PB7分开。按原理图，U7第1脚为5V、第2脚为GND、第3脚为SCL、第4脚为SDA。仅在模块明确支持5V输入并带稳压时使用该5V脚；3.3V模块改接主板3V3电源。裸MPU6050芯片不可直接接5V。模块和主板必须共地，SCL/SDA保持3.3V逻辑，模块上的上拉不能拉到5V。

模块平放固定于车身，Z轴箭头朝上，避免松动和电机强振动。AD0接低/高对应0x68/0x69，驱动自动识别这两个地址；WHO_AM_I须为0x68。INT、XDA、XCL不使用。IMU_YAW_SIGN默认-1，将Z轴朝上模块的逆时针正值转换成顺时针/右转为正；安装与轴向必须在实车上手动确认，当前没有验证。

## 上电与启动

上电保持车和车轮静止，OLED显示CAL，约3秒收集300个连续样本作零偏校准。晃动、车轮运动或姿态不平会重置校准窗口；稳定方差判据不能识别持续匀速的缓慢手转，因此必须静置。校准完成显示IDLE，再将车尾对准起跑横线并摆正，按KEY1启动。每次启动只将相对航向清零，沿用本次上电零偏；停止后不自动将静止零偏重新估计。

未连接/未完成校准时按KEY1会保持电机停止并显示故障12。校准中的12可等IDLE条件满足后再次按KEY1；模块离线或驱动错误需要连接好后RESET。运行中读取失败或样本超过30ms没有更新会停车并显示故障13，不自动退回编码器转角控制。KEY2始终优先停车。原V6已取消的编码器停转/反向反馈故障3/4继续保留为空号，不重新启用。

## 控制行为

直线由编码器速度内环和陀螺仪航向PD控制组成，目标航向为0/90/180/270/360度。保持V8/V9直线400、直线末段200、终点240mm/s，及固定0.5%右向前馈；航向修正两侧各最多80mm/s，PWM限幅和加减速参数保持。

八路仅在直线/终点段用于边界避让：左边界使目标航向暂向右偏，右边界暂向左偏，最大6度，按60度/秒限制目标变化。离开黑线或遇到宽横线后平滑恢复本段名义航向，不把八路差速直接叠加到航向PD。全白时只能保持航向，不能判断横向偏移；边界越过探头横排中点后的方向仍有歧义，不承担越界找回。灰度高低电平和X1方向沿用V9待实测配置。

转弯期间暂停八路采样和横线处理。用MPU6050实测航向对准下一90度目标，角度误差<=2度且转动速度<=10度/秒后直接进入下一直线，没有固定停等。接近目标时角速度和前进速度按比例同时下降，保持名义125mm中心半径。若轻微过转，允许低速反向修正航向，方向正确后继续前进。

首段944mm、后续三段1300mm、终点最大450mm仍按两侧编码器平均路程决定，轮径41.5mm、CPR1040沿用待标定值。弯道中心速度244mm/s为上限，原弯末固定122mm/s改成按剩余角度连续减速。旧转弯差动增益1.58097304仅作为轮速差的初始前馈，不再决定转弯结束；圆弧左右参考行程仍用于串口诊断，实际转弯行程随陀螺仪闭环和打滑而改变，不能保证与V9完全相同。

## 软件与观测

新增App/Inc、App/Src中的imu和imu_bus：独立开漏软件I2C，每次传输总超时4ms，运行时无HAL_Delay、无关闭中断。boot复位/稳定只延时100+50ms，电机保持停止。MPU6050使用±500度/秒、65.5LSB/(度/秒)、±2g、DLPF=3、传感器200Hz；控制每10ms读取INT_STATUS和14字节数据，只有新样本参与校准和积分。角度为连续累计，支持经过360度；没有磁力计，不能消除长期航向漂移。

串口保留原字段，增加imu状态(0离线/1校准/2就绪/3错误)、cal样本数、yaw10航向、rate10角速度、ref10名义目标、off10边界偏置，后三类角度数值均乘10。OLED保留状态、计时、路程、速度与故障显示。首次接模块后应先在不启动电机的状态确认：静置完成校准，手动右转约90度时yaw10应增加约900；软件写好不等于硬件方向已确认。

Keil工程MDK-ARM/STM32_D_Route.uvprojx已加入两个新源文件。成功构建输出为MDK-ARM/Objects/STM32_D_Route.hex，已复制为Firmware/STM32_D_Route_V10.hex；V9命名固件保留供回退。首次低速标定可将ROUTE_STRAIGHT_SPEED_MM_S/ROUTE_ARC_CENTER_SPEED_MM_S等速度值降低，同时保持相关上限关系。当前默认值继续沿用已有速度要求，不保证实际地面速度、直线距离或90度精度。
